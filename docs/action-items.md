## 2026-11-26 요청 (C1–C4)

### C1. 칸 이름 바꾸기: Category / MID / Sub Category → Project / Type / Task
- 영어 화면의 칸 이름을 바꿉니다. Content는 그대로.
  | 지금 | 바꿀 이름 |
  |---|---|
  | Category | Project |
  | MID | Type |
  | Sub Category | Task |
- 바꿀 곳: Daily Log 표 머리글, 휴대폰 입력 창, 30분 알림 입력 창, 반복 업무 안내 글, 행 앞 + 버튼 설명, Projects 화면의 MID 카드(제목, "MID 추가" 버튼, 안내 글), Weekly Result, README.
- 바꾸지 않을 것: 저장된 데이터와 DB 이름(`work_types` 등), 회사 양식 엑셀 내보내기의 머리글, 엑셀 붙여넣기 규칙.
- **정할 것:** 한국어 화면의 이름. 지금은 대분류 / 중분류 / 업무분류 / 업무내용입니다. 그대로 둘지, 프로젝트 / 유형 / 업무처럼 영어에 맞출지. Projects 화면은 프로젝트 묶음을 "대분류·소분류"라고 부르고 있어서, 표의 "대분류"(실제로는 프로젝트)와 헷갈릴 수 있습니다.
- 완료 기준: 영어·한국어 화면 모두 새 이름으로 보이고, 저장·붙여넣기·엑셀 내보내기가 전과 같이 동작.

### C2. 행 앞 + 칸과 Time 칸 사이에 세로 줄
- + 버튼 칸과 Time 칸이 붙어 보여서, 사이에 세로 줄을 넣어 칸을 확실히 나눕니다. 다른 칸 사이의 줄과 같은 모양으로.
- 바꿀 곳: `src/pages/timesheets/grid/DailyGrid.tsx`(머리글과 각 행의 + 칸).
- 완료 기준: 머리글부터 마지막 행까지 + 칸 오른쪽에 줄이 이어져 보이고, + 버튼 동작과 열 너비 조절은 그대로.

### C3. 반복 업무 … 메뉴 맨 위에 Project · Type 표시
- 지금 … 메뉴 맨 위에는 업무 이름(예: "개발 | 커머셜 워크램프")만 보여서, 어느 프로젝트의 어떤 일인지 알기 어렵습니다.
- 맨 윗줄에 **Project · Type**을 보여 주고, 그 아래에 지금처럼 업무 이름(더블클릭으로 고치기)을 둡니다. Type이 없으면 Project만.
- 바꿀 곳: `src/pages/timesheets/DailyLog.tsx`의 반복 업무 메뉴(ColorMenu에 넘기는 제목).
- 완료 기준: 메뉴를 열면 맨 위에 그 반복 업무의 Project와 Type이 프로젝트 색과 함께 보이고, 이름 고치기·삭제·색 바꾸기는 그대로.

### C4. 반복 업무를 표로, 자주 쓰는 업무를 앞 번호에
- 칩 모양 대신 표로 보여 줍니다. 칸: No · Project · Type · Task (색, … 메뉴).
- 순서를 바꿔 자주 쓰는 업무를 앞 번호(0–5번)에 둘 수 있게 합니다. 순서는 이미 사용자별로 저장되고 있습니다(`task_templates.sort_order`). 지금은 칩을 끌어서 바꿉니다.
- 누르면 고른 칸에 적용되는 동작은 지금과 같게.
- **정할 것:**
  1. 위치: 지금 오른쪽 열은 좁아서(약 340px) 4칸 표는 빠듯합니다. 오른쪽 열에 둘지, Today처럼 떼어 낼 수 있는 도킹 창으로 만들지, 표 아래에 둘지. (반복 업무 카드를 어디에 둘지는 Today 창을 써 보고 정하기로 했던 부분입니다.)
  2. 번호: 0부터 시작할지 1부터 시작할지. 숫자 키(0–5)를 누르면 바로 적용되는 단축키까지 원하는지, 아니면 앞쪽에 두는 것만인지.
  3. 순서 바꾸기: 끌어서 옮기기, Projects 화면처럼 No 더블클릭해서 번호 고치기, 또는 둘 다.
- 완료 기준: 표로 보이고, 순서를 바꾸면 새로 고쳐도 유지되며, 행을 누르면 고른 칸에 적용됨. 휴대폰에서도 가로로 넘치지 않음.
