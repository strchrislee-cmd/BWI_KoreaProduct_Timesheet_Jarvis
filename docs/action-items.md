## 2026-11-26 요청 (D1–D4)

### D1. 자동 줄바꿈 켜기/끄기 체크박스
- 지금은 칸 너비를 줄이면 긴 글이 두 줄, 세 줄로 늘어나 행이 길어집니다(2026-11-24에 "긴 글이 잘려 보임"을 고치며 넣은 동작).
- **자동 줄바꿈** 체크박스로 고를 수 있게 합니다.
  - 켬: 지금처럼 줄바꿈, 행이 늘어남.
  - 끔: 한 줄로, 넘치는 글은 …로 줄이고 마우스를 올리면 전체 글.
- 사람마다 저장(행 높이·열 너비 설정과 같은 곳).
- **정할 것:**
  1. 위치. 후보: 표 아래 "행 높이 좁게/보통/넓게" 옆, 30-min Log 제목줄, Settings.
  2. 반복 업무 표에도 같이 적용할지.

### D2. 창 배치 편집: 30-min Log · Today · 반복 업무 창의 크기·위치
- 세 창의 **크기 조절**과 **위치 이동**.
- 옮기기 시작하면 배경에 일정 간격의 **점(· · ·) 그리드**가 보이고, 창은 그리드에 맞춰 놓입니다.
- 편집하는 동안 창이 아이폰 홈 화면 편집처럼 **살짝 흔들흔들**.
- 화면 아래 토스트: **"배치를 저장하겠습니까?"** [저장] [취소] [기본 설정으로].
- 배치는 **사용자마다 저장**해서, 다시 들어오면 그 배치로 보입니다.
- **정할 것:**
  1. 편집 시작 방법: "배치 편집" 버튼, 창 제목줄을 길게 누르기, 또는 둘 다.
  2. 저장 위치: 계정에 저장(다른 PC에서도 같은 배치, 추천)인지, 그 브라우저에만인지.
  3. 휴대폰은 지금처럼 고정 배치로 둘지(추천).
  4. "전체 UI 크기"가 세 창의 크기만 뜻하는지, 화면 전체 확대·축소(예: 90% / 100% / 110%)도 원하는지.
- D4와 겹치는 부분(Today·반복 업무 창의 위치)이 있어 함께 설계하는 것이 좋습니다.

### D3. Today 그래프 보기(도넛)
- Today 창에 **그래프 보기**를 추가: 오늘 시간이 어디에 몇 % 쓰였는지 원형 도넛 차트로. 가운데에 합계 시간.
- 목록 보기 ↔ 그래프 보기 전환 버튼. 색은 프로젝트 색 그대로.
- **정할 것:**
  1. 나누는 기준: Project별(지금 Today 목록과 같음), Type별, 또는 둘 다 전환.
  2. %의 기준: 오늘 기록한 시간 합계 대비인지, 목표(8h) 대비(남은 시간을 빈 칸으로 표시)인지.
  3. 점심·비업무를 넣을지.

### D4. Today·반복 업무를 오른쪽 가장자리 Dock으로
- 아래 Dock처럼 **화면 오른쪽에 붙여 두는** 모드를 버튼으로 추가. 붙여 둔 창은 오른쪽 끝에 표시됩니다.
- **자석처럼 붙이기** 체크박스: 켜면 오른쪽 끝 근처로 끌 때 달라붙고, 끄면 붙지 않고 놓은 자리에 떠 있음.
- **정할 것:**
  1. 오른쪽에 붙인 창도 아래 Dock처럼 평소엔 숨었다가 마우스를 오른쪽 끝에 가져가면 나타날지, 늘 보일지.
  2. 버튼과 체크박스 위치: 각 창의 제목줄, 또는 Settings.
- D2와 함께 설계(위 참고).
