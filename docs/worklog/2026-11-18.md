## 작업 내용

### 1. 1단계 앱 (`df86e97`)
- React 19 + Vite + TypeScript, Tailwind, React Router. Vercel 배포 구성(`vercel.json`, 서울 리전)
- Supabase 스키마·권한(RLS)·초대 전용 가입·마지막 관리자 보호·마스터 반영 함수(`apply_master_import`, 중복 파일 무시)
- 화면: Daily Log, Weekly Plan, Group Timesheet, Projects, Leave, Settings, Admin, Login, Home(빈 위젯)
- 엑셀: 그룹 마스터·개인 30분 로그 읽기, 그룹 포맷·주간계획 내보내기
- 데모 모드(브라우저 저장), Vercel 함수 `/api/ingest`(Power Automate 수신), `/api/admin/invite`

### 2. 엑셀/노션식 그리드 (`2f877cc`)
- 여러 칸 선택·한 번에 입력, 엑셀 호환 복사·붙여넣기, Delete·Ctrl+D·Ctrl+Z
- 노션식 검색 드롭다운, 개인별 **반복 업무**, 점심시간 기본 '점심'
- 한글 IME 입력이 거꾸로 들어가던 문제("워크" → "크워") 발견·수정

### 3. 근무 시작·종료와 색상 (`75cb680`)
- 날짜별 시작·종료(시작 + 근무 8h + 점심 1h, 연장 가능), Settings 기본값
- 카테고리·반복 업무 색상(프리셋, RGB, 내 색상 보관)
