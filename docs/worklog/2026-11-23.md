## 3. 배경: 오른쪽 → 왼쪽으로 흐르는 물결
**요청** 일렁이는 형태 대신, 단순하게 화면 오른쪽에서 왼쪽으로 흐르게. 물결 모양은 패턴마다 조금씩 다르게.

**작업 내용**
- 셰이더를 새로 만들었습니다. 오늘의 색 6개가 **부드러운 물결 모양 띠**로 쌓이고, 그 띠가 **오른쪽에서 왼쪽으로 계속 흘러갑니다.**
- 일렁임과 색 변화는 없앴습니다.
- 물결 모양은 패턴(시드)마다 다릅니다.
  - 화면 폭당 큰 물결 1–2개와 잔물결 2–5개
  - 물결의 높이, 위상, 기울기
- 물결 개수를 정수로 맞춰서 흘러가는 동안 이음매 없이 반복됩니다.
- 기존 시드의 **색은 그대로** 두고 물결 모양만 더했습니다. 오늘 보던 색이 바뀌지 않습니다.
- 속도는 물결이 화면을 지나가는 시간으로 표시합니다: 느리게 24초 / 보통 12초(기본) / 빠르게 6초. 미리보기와 배경에 바로 반영됩니다.
- WebGL이 없는 브라우저에서는 같은 색 띠를 멈춘 그림으로 보여 줍니다.

**작업 결과**
- 브라우저에서 배경 화면의 화소를 비교해 **실제로 왼쪽으로 이동**하는 것을 확인했습니다(빠르게, 0.7초에 76px).
- 단위 테스트로 100개 시드의 물결 모양이 모두 다르고, 물결 개수가 정수(이음매 없음)인 것을 확인했습니다.

## 7. 패널 불투명도 슬라이더

**작업 내용**

- 드롭다운·메뉴·창은 이전 요청대로 항상 불투명합니다(슬라이더와 무관).

**작업 결과**

- 리퀴드로 바꾸면 22%에서 시작하고, 다시 블러로 오면 90%가 그대로입니다.
- 휴대폰 폭(390px)에서도 가로 스크롤 없이 들어갑니다.

- 숨긴 항목은 번호 없이 "–"로 보이고, 나머지 번호는 빈칸 없이 이어집니다.
- 직접 추가한 항목은 그 대분류의 맨 뒤 번호를 받고, 그 뒤 번호는 하나씩 밀립니다.
- 번호는 저장하지 않고 화면에서 계산합니다(DB 변경 없음).

**작업 결과** 마스터 시트를 올린 상태에서 1~35가 순서대로 이어지고, 필터·숨기기·되돌리기·추가 후에도 번호가 맞는 것을 확인했습니다(브라우저 테스트 11단계).

## 9. 드롭다운 정렬에 "타임시트 번호순"

**작업 내용**

- 다른 정렬처럼 개인 설정으로 기억합니다.
- 업무분류(반복 업무) 칸에는 No가 없어서 이 정렬을 넣지 않았습니다.

**작업 결과** 이름 역순에서 번호순으로 바꾸면 PROJECT RND가 Project mapping의 No 1부터 순서대로 나오고, 새로고침 후에도 유지되는 것을 확인했습니다.

## 12. 관리자가 No와 이름 고치기 (더블클릭)

  - 예전 시트를 다시 올려도 이 이름으로 같은 항목을 찾습니다. 신규나 "시트에 없음"으로 나오지 않고, 앱에서 바꾼 이름이 유지됩니다.

  - 데모 모드에도 같은 규칙을 넣었습니다.

## 13. 프로젝트 목록 저장/불러오기 (.json)
**작업 내용**
- **목록 저장 (.json)**: 표 순서대로 모든 항목을 `timecrumbs-projects-날짜.json`으로 내려받습니다.
  - 담는 내용: 대분류, No, 이름, 시트 이름, 코드, 직접 추가 여부, 숨김, 로컬 별칭.

  - 보여 주는 항목: 이름 변경, 추가, 순서 변경 수, 다시 표시/숨김, 별칭 추가, 건너뜀, 파일에 없어 그대로 둠.
  - **불러오기 적용**을 눌러야 반영됩니다.
- 항목은 이 순서로 맞춥니다: 기본 항목 키 → 프로젝트 코드 → 이름 또는 시트 이름.
- 맞는 항목은 파일의 이름·순서·숨김을 따릅니다. 새 항목은 추가하고, 별칭은 추가만 합니다(지우지 않음).
- 파일에 없는 항목은 그대로 두고 맨 뒤로 보냅니다.
- 기본 항목(휴가·회의 등)은 숨기지 않습니다. 대분류가 다른 같은 이름은 건너뜁니다.
- 순서가 실제로 바뀌는 대분류만 번호를 다시 매깁니다. 같은 파일을 다시 불러오면 "바뀌는 내용이 없습니다"가 나옵니다.

**작업 결과**

## 14. 등급 L1 / L2 / L3
**작업 내용**
- 역할은 **Admin / L1 / L2 / L3** 네 가지입니다.
  - 관리 화면의 사용자 목록과 초대에서 등급을 고릅니다.
  - 왼쪽 메뉴 아래에 내 등급이 보입니다.
- L1·L2·L3가 지금 할 수 있는 것(셋 다 같음):
  - 본인 기록·휴가·근무시간·반복 업무

  - 내 별칭, 색과 정렬 같은 개인 설정
- 다른 사람 자료 보기는 지금은 관리자만 됩니다. 예전 viewer의 "전원 읽기"는 없어졌습니다.
  - 다음 단계에서 등급별 그룹 열람(예: L2 → 자기 그룹의 L1)을 붙일 수 있게 구조를 열어 두었습니다.

## 15. 관리자 설정 표시 (수정 불가)

- Group Project 머리글과 팀 별칭에 🔒가 붙습니다. 추가·이름 변경·숨김·목록 불러오기 버튼은 보이지 않습니다.
- No나 이름을 더블클릭하면 "🔒 관리자 설정이라 수정할 수 없습니다"라는 안내가 뜨고, 편집 칸은 열리지 않습니다.

## 16. 내 별칭 (개인 설정)
**작업 내용**
- 별칭은 두 가지입니다.
  - **팀 별칭**: 관리자가 넣고, 모두에게 적용됩니다.
  - **내 별칭**: L1–L3가 넣고, **본인 기록에만** 적용됩니다.
- 내 별칭이 쓰이는 곳: Projects 표의 "+ 내 별칭", Daily Log의 "매핑 안 된 카테고리" 연결, 엑셀 가져오기의 연결.
- 내 별칭은 점선 테두리에 "내" 표시가 붙고, 본인이 지울 수 있습니다. 다른 사람은 볼 수 없습니다(관리자는 그 사람 기록을 볼 때 함께 봅니다).
- 같은 글자의 팀 별칭이 이미 있으면 내 별칭으로 넣을 수 없습니다(이미 적용 중이므로). 다른 사람과는 같은 글자를 써도 됩니다.
- 내 기록을 해석할 때는 내 별칭이 팀 별칭보다 먼저 적용됩니다.
- 목록 저장(.json)에는 팀 별칭만 담습니다. 개인 별칭은 각자에게 남습니다.
- DB:
  - `project_aliases.user_id`: 비어 있으면 팀 별칭, 채워져 있으면 그 사람의 개인 별칭입니다.
  - 중복 검사를 팀/개인으로 나눴습니다.
  - 권한: 팀 별칭은 관리자만 추가·삭제합니다. 개인 별칭은 본인이 추가·삭제하고, 본인과 관리자만 볼 수 있습니다.
  - 예전에 member가 넣은 별칭은 그 사람의 개인 별칭으로 옮깁니다.

**작업 결과** 데모에서 L1로 바꿔 확인했습니다.
- 잠금 표시가 나오고 편집할 수 없습니다.
- 내 별칭 "내휴가"를 추가하면 Daily Log에서 그 글자가 휴가 프로젝트로 연결됩니다.
- 팀 별칭과 같은 글자는 거절됩니다.
- 관리자로 돌아가 저장한 목록에는 내 별칭이 들어가지 않습니다.
