## 3. 배경: 오른쪽 → 왼쪽으로 흐르는 물결
**요청** 일렁이는 형태 대신, 단순하게 화면 오른쪽에서 왼쪽으로 흐르게. 물결 모양은 패턴마다 조금씩 다르게.

**작업 내용**
- 셰이더를 새로 만들었습니다. 오늘의 색 6개가 **부드러운 물결 모양 띠**로 쌓이고, 그 띠가 **오른쪽에서 왼쪽으로 계속 흘러갑니다.**
- 일렁임과 색 변화는 없앴습니다.
- 물결 모양은 패턴(시드)마다 다릅니다.
  - 화면 폭당 큰 물결 1–2개와 잔물결 2–5개
  - 물결의 높이, 위상, 기울기
- 물결 개수를 정수로 맞춰서 흘러가는 동안 이음매 없이 반복됩니다.
- 기존 시드의 **색은 그대로** 두고 물결 모양만 더했습니다. 오늘 보던 색이 바뀌지 않습니다.
- 속도는 물결이 화면을 지나가는 시간으로 표시합니다: 느리게 24초 / 보통 12초(기본) / 빠르게 6초. 미리보기와 배경에 바로 반영됩니다.
- WebGL이 없는 브라우저에서는 같은 색 띠를 멈춘 그림으로 보여 줍니다.

**작업 결과**
- 브라우저에서 배경 화면의 화소를 비교해 **실제로 왼쪽으로 이동**하는 것을 확인했습니다(빠르게, 0.7초에 76px).
- 단위 테스트로 100개 시드의 물결 모양이 모두 다르고, 물결 개수가 정수(이음매 없음)인 것을 확인했습니다.
- 움직임 GIF: `d_05_flow_right_to_left.gif`(레포에는 커밋하지 않음)

## 4. 프로젝트 목록 추가
**요청** PROJECT_RND 21개, PROJECT_CO_WORK 7개, PROJECT_NON_RND 8개를 프로젝트에 추가해 달라.

**판단**
- RND 목록에는 실제 고객사·브랜드 이름이 들어 있습니다.
- 이 저장소는 공개이고 데모 주소도 공개라서, 처음 정한 원칙대로 **코드·기본 데이터·레포에 넣지 않았습니다.**

**작업 내용**
- 목록으로 **마스터 시트 엑셀**(`No.` / `Project` 열, 28행)을 만들어 사용자에게 따로 전달했습니다. 레포에는 넣지 않았습니다.
  - Projects → Group master sheet에서 올리면 사용자 브라우저(나중에는 비공개 Supabase)에만 들어갑니다.
  - 붙여 넣은 목록 중 25번 항목 이름 가운데에 끼어 있던 줄바꿈 공백("문    제")은 원래 이름("문제")으로 고쳤습니다.
- **CO_WORK 7개**(00.Timelog)는 이미 기본 데이터에 있어서, 올리면 '일치'로 처리됩니다.
- **NON_RND**
  - 7개는 이미 기본 Section에 있습니다.
  - 목록에서 이름이 다른 한 항목("금형 Support" 앞에 회사 표기를 붙인 이름)으로 바꿀 수 있도록 **Section·직접 추가 항목 이름 변경**(관리자, ✏ 버튼)을 추가했습니다. 회사 표기는 공개 레포라 여기 적지 않습니다.
  - 마스터 시트에서 온 이름은 다음 업로드 때 시트 이름으로 돌아가기 때문에 바꿀 수 없게 했습니다.
  - "Indivisual Sum"은 카테고리가 아니라 Group Timesheet의 **자동 합계 행**이라 추가하지 않았습니다.
- DB 테스트에 이름 변경 권한(관리자만, 매칭 키 갱신)을 추가했습니다.

**작업 결과**

  - 미리보기에서 **신규 21 / 일치 7**로 나옵니다.
