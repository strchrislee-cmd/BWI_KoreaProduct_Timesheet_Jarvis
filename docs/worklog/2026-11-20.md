## B3. 리퀴드 글래스 스타일
**요청** 지금의 블러 스타일 외에 애플 iOS 26의 리퀴드 글래스처럼 배경이 비치고 가장자리가 휘어 보이는 스타일을 옵션으로 추가.

**작업 내용**
- Settings에 **화면 스타일** 카드를 추가했습니다. 블러(기본)와 리퀴드 글래스 중에서 고릅니다.
- 리퀴드 글래스의 모습:
  - 블러를 거의 없애 배경이 그대로 비칩니다(2px).
  - 유리 위쪽은 밝고 아래쪽은 투명해지는 광택을 넣었습니다.
  - 가장자리에 빛을 받는 테두리를 넣었습니다.
- **가장자리 휘어짐**은 SVG 왜곡 필터로 만들었습니다(`src/lib/liquidGlass.ts`). 가운데는 그대로 두고 가장자리 쪽만 배경을 렌즈처럼 당깁니다.
  - 이 효과는 Chrome·Edge만 그려 줍니다.
  - 다른 브라우저는 휘어짐 없이 맑은 유리로만 보이고, 그때는 Settings에 안내 문구가 나옵니다.
- 드롭다운·메뉴·모달은 글자를 읽기 쉽게 지금보다 조금 맑게만 하고, 휘어짐은 넣지 않았습니다.
- 선택한 스타일은 사용자 설정(`uiStyle`)에 저장됩니다.

**작업 결과**
- 리퀴드 글래스를 고르면 카드에 왜곡 필터가 적용되고, 드롭다운에는 적용되지 않는 것을 확인했습니다.
- 새로고침 후에도 유지되고, 블러로 되돌리면 원래 모습이 됩니다.
- 시작 전에 시험 페이지로 Chromium에서 가장자리가 실제로 휘는지 먼저 확인했습니다.
- 스크린샷: `b_03_liquid_daily.png`, `b_04_settings.png`(레포에는 커밋하지 않음)

## B4. 물결처럼 흐르는 그라데이션
**요청** 오늘의 그라데이션 색이 바다나 파도처럼 계속 천천히 흐르고 변하게. 기본은 켜짐, 느린 속도.

**작업 내용**
- 오늘 날짜로 정해진 색은 그대로 두고, 세 가지 움직임을 계속 반복합니다:
  - 색 덩어리 4개가 서로 다른 주기(46–64초)로 둥글게 흘러 다닙니다.
  - 전체 색이 80초에 걸쳐 조금씩 바뀌었다가 돌아옵니다(색상 ±16°).
  - 옅은 빛의 띠가 36초마다 한 번씩 가로질러 지나갑니다.
- Settings → 배경:
  - **물결처럼 흐르기**(기본 켜짐)
  - **속도** 느리게(기본) / 보통 / 빠르게. 빠르게는 느리게보다 약 3배 빠릅니다.
- 부담 줄이기:
  - 움직임은 그래픽 카드가 처리하는 방식(transform·filter)만 썼습니다.
  - 다른 탭을 보는 동안은 멈춥니다.
  - OS의 '동작 줄이기'가 켜져 있으면 움직이지 않고, Settings에 그 이유가 표시됩니다.

**작업 결과**
- 기본으로 움직임 6개(색 변화 1, 색 덩어리 4, 빛의 띠 1)가 돌아가는 것을 확인했습니다.
- 속도를 빠르게 바꾸면 색 변화 주기가 80초에서 24초로 줄어듭니다.
- 탭을 숨기면 멈추고, 끄면 정지하고, 동작 줄이기 환경에서는 움직이지 않습니다.
- 움직임은 `b_01_flowing_gradient.gif`(60초를 압축해 보여 주는 GIF)로 확인할 수 있습니다.

## B5. Project mapping: 추가·숨김·되돌리기·색상
**요청**
- Project mapping에서 데이터를 추가하거나 삭제할 수 있게. 관리자만.
- 색상을 지정할 수 있게 하고, Daily Log 색과 연동. 색상은 개인별.
- 직접 추가한 프로젝트가 나중에 마스터 시트에 같은 이름으로 들어오면 자동으로 합치고 NEW 표시 안 함.
- 마스터에 있는 프로젝트를 '삭제'하면 숨김 처리(되돌리기 가능).

**작업 내용**
- DB: `supabase/migrations/0006_project_manage.sql`
  - 칼럼: `hidden`(숨김), `manual`(직접 추가)
  - `add_group_project()`(관리자만)
    - 이름의 공백을 정리합니다.
    - 같은 이름이 있으면 거부합니다. 숨긴 항목과 이름이 같으면 "되돌리기를 쓰라"고 안내합니다.
  - `remove_group_project()`(관리자만)
    - 직접 추가했고 아직 기록·반복 업무에 쓰이지 않았으면 실제로 삭제합니다.
    - 그 밖에는 숨깁니다.
    - 기본 항목(휴가·회의 등 시스템 행)은 삭제할 수 없습니다.
  - 마스터 반영 함수(`apply_master_import`)를 고쳤습니다.
    - 직접 추가한 프로젝트가 마스터에 같은 이름·코드로 오면 합칩니다. 처음 들어온 프로젝트로 치지 않으므로 NEW가 뜨지 않습니다.
    - 직접 추가한 프로젝트가 마스터에 없어도 '시트에서 빠짐'으로 표시하지 않습니다.
    - 숨긴 프로젝트는 다시 올라와도 숨긴 상태 그대로입니다.
- 화면(Projects → Project mapping):
  - 관리자용 입력 줄: 이름, 종류(Project / Timelog / Section), **추가**. Timelog는 이름 앞에 `00.Timelog--`가 자동으로 붙습니다.
  - **색상 칸**: 누구나 자기 색을 바꿉니다. Daily Log의 같은 카테고리 색과 같은 값이라 어느 쪽에서 바꿔도 양쪽에 반영됩니다.
  - 🗑 버튼
    - 마스터에서 온 항목: 확인 없이 바로 숨깁니다. 되돌릴 수 있기 때문입니다.
    - 직접 추가한 항목: 확인 창을 띄웁니다. 실제로 삭제될 수 있기 때문입니다.
  - **숨긴 항목 보기 (n)**: 숨긴 항목을 "숨김" 표시와 **되돌리기** 버튼과 함께 보여 줍니다.
  - 상태 칸에 "직접 추가" 표시를 붙였습니다.
- 숨긴 프로젝트는 다음 목록에서 빠집니다:
  - Daily Log 드롭다운
  - 미매핑 연결 목록
  - Import 마법사
  - Settings 색상 목록
  - NEW 알림
- 이미 기록된 칸은 숨긴 뒤에도 그 프로젝트를 그대로 보여 줍니다. Group Timesheet도 그 주에 시간이 있는 동안에는 숨긴 프로젝트 행을 보여 줍니다.
- 데모 모드(`LocalStore`)도 같은 규칙으로 동작합니다.

**작업 결과**
- DB 테스트 19개를 추가했습니다:
  - 멤버의 추가·삭제·되돌리기 거부
  - 중복 이름 거부
  - 안 쓰인 직접 추가 → 삭제, 쓰인 것 → 숨김
  - 기본 항목 거부
  - 다시 올려도 숨김 유지, 합치기·NEW 없음, '시트에서 빠짐' 미표시
- 브라우저 테스트에서 화면 동작을 처음부터 끝까지 확인했습니다:
  - 추가 → 색 지정 → Daily Log에서 같은 색 확인
  - Daily Log에서 색 변경 → Projects에 반영
  - 숨김 → 드롭다운에서 사라짐 → 되돌리기
  - 삭제(확인 창) / 쓰인 항목은 숨김
  - 마스터 재반영 시 합치기·숨김 유지
- 스크린샷: `b_05_projects_color.png`, `b_06_projects_hidden.png`

## B10. 아이폰 같은 작은 R
**요청** 알약처럼 둥근 버튼 대신 R이 작은 아이폰 같은 벤토 디자인.

**작업 내용**
- R 값을 4단계로 정해(`src/styles.css`) 모든 화면에 적용했습니다. 이전에는 80곳 정도가 알약 모양이거나 큰 R이었습니다.

  | 요소 | 이전 | 이후 |
  |---|---|---|
  | 벤토 카드, 왼쪽 메뉴 | 24px | 16px |
  | 메뉴·드롭다운·모달 | 12–24px | 12px |
  | 버튼·입력칸·탭·왼쪽 메뉴 항목·안내 문구 | 알약~16px | 10px |
  | 칩·상태 표시·색상 견본·드롭다운 옵션 줄 | 알약~12px | 6px |
  | 프로필 이니셜, 현재 시간 점 | 원 | 원(유지) |

- Chrome·Edge에서는 모서리를 아이폰처럼 부드럽게 이어지는 곡선으로 그립니다(`corner-shape: superellipse(1.5)`). 다른 브라우저는 일반 둥근 모서리입니다.
- 닫기(X) 같은 작은 아이콘 버튼은 10px로 맞췄습니다. 날짜 칩이나 칸 안처럼 좁은 곳의 작은 버튼은 바깥 모양과 어울리게 6px로 했습니다.
- `concept-design/README.md`의 디자인 기준 값도 고쳤습니다.

**작업 결과** 브라우저에서 실제 값을 확인했습니다: 카드 16px, 버튼·탭 10px, 칩 6px, 모달 12px, 곡선 모서리 적용, 프로필 이니셜은 원형 유지.
