# 2026-11-26 작업 기록

## 1. MID(중분류) 추가
**요청**
- 일의 종류를 나타내는 MID 카테고리를 추가하고 싶다. 신규개발·파생개발, 생산지원·8D지원, 회의-INT·EXT 외에 무엇을 둘지 제안해 달라.
- 결정(질문으로 확인): 일반-이메일 및 일반업무 추가, 관리-문서·보고 제외. 위치는 대분류 다음 칸, 선택 사항, Weekly Result의 Work 열을 MID로(화면·엑셀), 반복 업무에 MID 포함, 엑셀 3칸 붙여넣기는 예전처럼, 칸 이름은 MID / 중분류.

**처음 목록(12개)**: 개발-신규 · 개발-파생 · 개발-설계변경 · 개발-선행검토 · 검증-시험·인증 · 검증-시제품 · 지원-생산 · 지원-8D · 지원-견적 · 회의-INT · 회의-EXT · 일반-이메일 및 일반업무

**작업 내용**
- DB 마이그레이션 `0011_work_types.sql`: `work_types` 표(이름 중복 불가, 순서, 팀 공통 색, 숨김), 모두 읽기·관리자만 쓰기, `time_slots`·`task_templates`에 `work_type_id`, `remove_work_type`(안 쓰였으면 삭제, 쓰였으면 숨김), 처음 목록 12개.
- Daily Log: 대분류 다음에 MID 칸(영문 MID, 한국어 중분류). 드롭다운에서 고르거나 입력하면 맞는 이름을 찾음(띄어쓰기·대소문자 무관), 목록에 없는 이름은 무시. MID 칩은 팀 공통 색. 칸 너비 조절 가능. 표가 카드보다 넓어지지 않게 기본 칸 너비를 조정.
- 붙여넣기: 엑셀에서 대분류 칸에 2~3칸을 붙이면 예전처럼 대분류·업무분류(·업무내용). 둘째 칸이 MID 이름이거나 4칸이면 MID 포함 순서대로. Daily Log 안에서 복사한 것은 칸 순서를 기억해 그대로 붙음. 복사에도 MID가 포함됨.
- 30분 알림 입력 창과 휴대폰 입력 창에 MID 선택 추가. 휴대폰 목록에도 MID 표시.
- 반복 업무가 MID를 함께 저장. MID 없는 반복 업무를 적용하면 행의 MID는 그대로.
- Weekly Result: Work 열에 MID(색 칩), 없으면 회의/기타. 대분류·업무분류가 같아도 MID가 다르면 다른 줄. 엑셀 내보내기의 Work 열도 같음.
- Projects 화면 아래 **MID** 카드: 관리자는 추가(MID 추가), 이름 더블클릭 수정, ↑↓ 순서, 색, 삭제(쓰였으면 숨김·되돌리기). L1~L3는 읽기만.
- 데모 저장소도 같은 규칙과 처음 목록(마이그레이션과 같은지 단위 테스트로 확인).

## 2. 행 앞 + 버튼: 반복 업무로 추가
- 시간 앞의 좁은 칸에 **+**. 누르면 그 행의 대분류·MID·업무분류가 반복 업무로 저장됩니다(업무내용·시간 제외). 이미 있으면 "이미 반복 업무에 있습니다". 빈 행과 기본 점심 행에는 없습니다.

## 3. 메뉴를 Dock으로
- PC에서 왼쪽 고정 메뉴를 없애고 화면 아래 가운데 **Dock**으로 바꿨습니다(질문으로 확인: 아래 가운데, 자동 숨김).

# (3차) 칸 이름 Project/Type/Task, + 칸 줄, 반복 업무 표, Dock 버그

## 1. 칸 이름 (C1)
- Category / MID / Sub Category → **Project / Type / Task**, 한국어 대분류 / 중분류 / 업무분류 → **프로젝트 / 유형 / 업무**. Content(업무내용)는 그대로.
- 바뀐 곳: Daily Log 머리글, 휴대폰 입력 창, 30분 알림 입력 창, 반복 업무 안내, + 버튼 설명, 드롭다운 안내, Projects 화면의 Type(유형) 카드(제목, **Type 추가**/**유형 추가**, 안내 문구), README.
- 그대로 둔 것: 저장된 데이터와 DB 이름(`work_types` 등), 회사 양식 엑셀 머리글, Weekly Result 열 이름(회사 양식), 엑셀 붙여넣기 규칙. Projects 화면의 프로젝트 묶음 이름(대분류·소분류)도 그대로입니다.

## 2. + 칸 오른쪽 세로 줄 (C2)
- + 칸과 Time 칸 사이에 다른 칸 사이와 같은 점선 세로 줄을 머리글부터 모든 행에 넣었습니다.

## 4. 반복 업무 표 (C4)
- 칩 대신 번호 표. No는 1부터. (같은 날 추가 요청으로 **No · Task 두 칸**으로 줄임: 처음엔 Project · Type 칸도 있었는데 정보가 너무 많아, Project · Type은 … 메뉴에서만 보이게 했습니다. Task는 프로젝트 색 칩으로 보여 색 설정이 계속 보입니다.)
- 행을 누르면 고른 칸에 적용(전과 같음). 행을 끌거나 **No를 더블클릭해 번호를 입력**하면 그 자리로 옮겨지고, 사람마다 저장됩니다(새로 고쳐도 유지).

- 휴대폰은 전처럼 입력 창에서 반복 업무를 고릅니다(창 없음).

## 5. Dock 버그 2건

- 저장하면 표·Task 드롭다운·휴대폰 입력 창에 **(내용 없음)**으로 보입니다(전에는 프로젝트 이름이 보였음). 이미 저장된 것도 같습니다.

## 2. 이름: 업무 빠른 등록
- 창 제목, 안내 문구, 드롭다운("“…” 생성 · 업무 빠른 등록에 추가"), + 버튼 설명, 휴대폰 입력 창, 저장 안내("업무 빠른 등록에 추가: …")를 모두 바꿨습니다. 저장된 데이터는 그대로입니다.

## 3. 자동 줄바꿈 (D1)
- 표 아래 "행 높이" 옆에 **자동 줄바꿈** 체크박스. 켜면 지금처럼 여러 줄(행이 늘어남), 끄면 한 줄로 …까지만 보이고 마우스를 올리면 전체 글. 사람마다 저장(행 높이와 같은 곳).

## 4. Today 그래프 (D3)
- Today 제목줄에 목록/그래프 버튼. 그래프는 도넛: 가운데 오늘 합계, 아래 항목별 %·시간. 조각이나 항목에 마우스를 올리면 그 항목의 %가 가운데에. 6개가 넘으면 작은 것들은 "기타". 고른 보기는 저장.
- %는 오늘 기록한 시간 중 비율입니다(목표 8h 대비가 아님). 색은 프로젝트 색 그대로.

## 5. 창 배치 편집 (D2)
- 30-min Log 제목줄 오른쪽 **배치 편집** 버튼, 또는 세 창(30-min Log · Today · 업무 빠른 등록) 중 아무 창의 제목줄(⠿)을 끌면 편집이 시작됩니다.
- 편집 중: 배경에 점 그리드(24px), 창이 아이폰 홈 화면처럼 살짝 흔들흔들(끄는 창은 멈춤). 제목줄을 끌어 옮기고, 오른쪽 아래 모서리를 끌어 크기 조절. 위치·크기는 점 간격에 맞춰집니다. 마지막으로 만진 창이 위로 옵니다.
- 아래 토스트 **"배치를 저장하겠습니까?"** [저장] [취소] [기본 설정으로].
- 배치는 계정(profiles.preferences)에 저장되어 다른 PC에서 로그인해도 같습니다. 휴대폰은 고정 배치.
- 배치를 바꾼 상태에서는 "새 그룹 프로젝트"·"매핑 안 된 카테고리" 알림 카드가 창들 아래에 나옵니다.

## 6. 오른쪽 Dock (D4)
- Today · 업무 빠른 등록 제목줄의 오른쪽 버튼으로 **오른쪽 Dock에 넣기/꺼내기**. 넣어 둔 창은 평소 숨어 있다가 마우스를 화면 오른쪽 끝으로 가져가면 나타나고, 멀어지거나 창 밖으로 나가면 숨습니다(아래 Dock과 같은 방식, 같은 코드).
