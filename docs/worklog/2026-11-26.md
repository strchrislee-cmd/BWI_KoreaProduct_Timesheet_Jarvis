# 2026-11-26 작업 기록

## 1. MID(중분류) 추가
**요청**
- 일의 종류를 나타내는 MID 카테고리를 추가하고 싶다. 신규개발·파생개발, 생산지원·8D지원, 회의-INT·EXT 외에 무엇을 둘지 제안해 달라.
- 결정(질문으로 확인): 일반-이메일 및 일반업무 추가, 관리-문서·보고 제외. 위치는 대분류 다음 칸, 선택 사항, Weekly Result의 Work 열을 MID로(화면·엑셀), 반복 업무에 MID 포함, 엑셀 3칸 붙여넣기는 예전처럼, 칸 이름은 MID / 중분류.

**처음 목록(12개)**: 개발-신규 · 개발-파생 · 개발-설계변경 · 개발-선행검토 · 검증-시험·인증 · 검증-시제품 · 지원-생산 · 지원-8D · 지원-견적 · 회의-INT · 회의-EXT · 일반-이메일 및 일반업무

**작업 내용**
- DB 마이그레이션 `0011_work_types.sql`: `work_types` 표(이름 중복 불가, 순서, 팀 공통 색, 숨김), 모두 읽기·관리자만 쓰기, `time_slots`·`task_templates`에 `work_type_id`, `remove_work_type`(안 쓰였으면 삭제, 쓰였으면 숨김), 처음 목록 12개.
- Daily Log: 대분류 다음에 MID 칸(영문 MID, 한국어 중분류). 드롭다운에서 고르거나 입력하면 맞는 이름을 찾음(띄어쓰기·대소문자 무관), 목록에 없는 이름은 무시. MID 칩은 팀 공통 색. 칸 너비 조절 가능. 표가 카드보다 넓어지지 않게 기본 칸 너비를 조정.
- 붙여넣기: 엑셀에서 대분류 칸에 2~3칸을 붙이면 예전처럼 대분류·업무분류(·업무내용). 둘째 칸이 MID 이름이거나 4칸이면 MID 포함 순서대로. Daily Log 안에서 복사한 것은 칸 순서를 기억해 그대로 붙음. 복사에도 MID가 포함됨.
- 30분 알림 입력 창과 휴대폰 입력 창에 MID 선택 추가. 휴대폰 목록에도 MID 표시.
- 반복 업무가 MID를 함께 저장. MID 없는 반복 업무를 적용하면 행의 MID는 그대로.
- Weekly Result: Work 열에 MID(색 칩), 없으면 회의/기타. 대분류·업무분류가 같아도 MID가 다르면 다른 줄. 엑셀 내보내기의 Work 열도 같음.
- Projects 화면 아래 **MID** 카드: 관리자는 추가(MID 추가), 이름 더블클릭 수정, ↑↓ 순서, 색, 삭제(쓰였으면 숨김·되돌리기). L1~L3는 읽기만.
- 데모 저장소도 같은 규칙과 처음 목록(마이그레이션과 같은지 단위 테스트로 확인).

## 2. 행 앞 + 버튼: 반복 업무로 추가
- 시간 앞의 좁은 칸에 **+**. 누르면 그 행의 대분류·MID·업무분류가 반복 업무로 저장됩니다(업무내용·시간 제외). 이미 있으면 "이미 반복 업무에 있습니다". 빈 행과 기본 점심 행에는 없습니다.

## 3. 메뉴를 Dock으로
- PC에서 왼쪽 고정 메뉴를 없애고 화면 아래 가운데 **Dock**으로 바꿨습니다(질문으로 확인: 아래 가운데, 자동 숨김).
  - 처음에 잠깐 보였다가 숨고, 마우스를 화면 아래 끝으로 가져가면 나타납니다. 아래쪽 가운데에 작은 막대로 위치를 표시합니다.
  - 아이콘에 마우스를 올리면 커지고(옆 아이콘도 조금), 위에 이름과 신 이름(Timesheets · Chronos 등)이 뜹니다. 현재 화면은 아이콘 아래 점.
  - 앱 이름과 사용자(로그아웃)는 Dock 안에 있습니다. 휴대폰은 하단 탭 바 그대로입니다.
- 왼쪽 메뉴 자리(168px)만큼 표가 넓어졌습니다.

## 4. Today 도킹 창
- Daily Log 오른쪽 **Today** 카드만 떼어 낼 수 있게 했습니다(반복 업무 카드는 결정 전까지 그대로, 질문으로 확인).
  - 제목줄을 끌면 떠서 표 위에 놓입니다. 끄는 동안 원래 자리에 점선 윤곽이 보입니다.
  - 화면 오른쪽 끝 근처로 끌면 원래 자리가 강조되고(자석), 놓으면 다시 붙습니다. 떠 있을 때 제목줄의 붙이기 버튼으로도 됩니다.
  - 떠 있는 위치는 이 브라우저에 기억합니다. 휴대폰은 늘 붙어 있습니다.

## 5. 함께 고친 것
